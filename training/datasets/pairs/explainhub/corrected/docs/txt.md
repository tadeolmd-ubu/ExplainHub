# Module: txt

| File | Purpose |
| ------ | ------ |
| `alterFormatter.js` | Formatter that renders ALTER statements for plain-text output |
| `apiFormatter.js` | Formatter that renders API sections for plain-text output |

| `dependencyFormatter.js` | Formatter that renders dependency sections for plain-text output |

| `dropsFormatter.js` | Formatter that renders DROP statements for plain-text output |
| `fileFormatter.js` | Formatter that renders file sections for plain-text output |
| `headerFormatter.js` | Formatter that renders document headers for plain-text output |
| `indexesFormatter.js` | Formatter that renders index definitions for plain-text output |
| `routinesFormatter.js` | Formatter that renders routine definitions for plain-text output |

| `tablesFormatter.js` | Formatter that renders table definitions for plain-text output |
